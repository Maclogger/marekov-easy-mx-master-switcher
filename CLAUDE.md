# Instructions for coding agents

You are probably running on the user's **Windows laptop** (`MAREKOV-WINDOWS`).

1. Start with [`LAN-MOUSE.md`](LAN-MOUSE.md). That is the current task: set up the Windows side
   of lan-mouse so the Linux machine's mouse and keyboard can drive this laptop.
2. [`TODO.md`](TODO.md) (a custom tray app) is **on hold**. Don't build it unless the user asks.
3. `reference/linux/` holds copies of the working Linux side, for reference only.

The user writes in English, sometimes via dictation, so expect odd words. Ask before anything
destructive. Git is allowed in this repo: commit and push your documentation updates.
